# Highlights

The "## Highlights" section of the next GitHub Release: 3-6 plain-language bullets of what users can now do.
Update it in the same change as the feature. CI fails when there are fewer than 3 or more than 6 bullets.

- Open contribution: anyone can propose an improvement by pull request, and Guten Group decides what merges.
- Every change to main now needs a code owner's review before it merges.
- Pull requests from forks never receive the repository's secrets, and a first-time contributor's checks start only after approval.
