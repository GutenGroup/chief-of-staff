# Highlights

The "## Highlights" section of the next GitHub Release: 3-6 plain-language bullets of what users can now do.
Update it in the same change as the feature. CI fails when there are fewer than 3 or more than 6 bullets.

- The Claude plugin directory now gets its own supervised edition: it reads your sessions, writes the brief and proposes next steps.
- In that edition every push, merge, publish, delete, send, payment, access change and session change waits for your explicit yes.
- Its README says what it reads and writes, and that it sends nothing to any service.
- The full install from GitHub is unchanged: only legal and money decisions reach you.
