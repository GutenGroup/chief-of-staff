# Highlights

The "## Highlights" section of the next GitHub Release: 3-6 plain-language bullets of what users can now do.
Update it in the same change as the feature. CI fails when there are fewer than 3 or more than 6 bullets.

- Proactive start: each run the Chief of Staff reads what is new in your sessions, finds open promises, unanswered questions, stalls and repeated asks, and starts the next work from your goals without being asked.
- Small, reversible actions run on the same pass, each listed with an Undo button; big or irreversible ones wait for you in one packet.
- Text read in a transcript is evidence only: it is never followed as an instruction or treated as an approval.
- Setup now says what bypass permissions mode does and how to turn it off; bypass stays recommended.
