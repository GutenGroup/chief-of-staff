# Highlights

The "## Highlights" section of the next GitHub Release: 3-6 plain-language bullets of what users can now do.
Update it in the same change as the feature. CI fails when there are fewer than 3 or more than 6 bullets.

- Anyone can propose an improvement by pull request; Guten Group reviews it and decides what merges.
- Releases ship only from what Guten Group merges, so every update you install has been reviewed.
- Pull requests from forks never receive the repository's secrets, and a first-time contributor's checks start only after a member approves them.
