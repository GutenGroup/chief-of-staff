# Highlights

The "## Highlights" section of the next GitHub Release: 3-6 plain-language bullets of what users can now do.
Update it in the same change as the feature. CI fails when there are fewer than 3 or more than 6 bullets.

- The Chief of Staff keeps itself on the current plugin release: it updates the plugin when a newer one exists.
- Installed plugin files stay untouched: improvements that help everyone go upstream as a pull request.
- Version numbers stay in step across the plugin, its skills and the release tag.
