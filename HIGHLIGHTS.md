# Highlights

The "## Highlights" section of the next GitHub Release: 3-6 plain-language bullets of what users can now do.
Update it in the same change as the feature. CI fails when there are fewer than 3 or more than 6 bullets.

- The Workspace panel now shows every action waiting on you, read live from the brief, waiting sessions and the COO reports.
- Each action has one-click buttons: open its link, file or session, mark it Done, or put it off for 3 hours with Later.
- Below the actions, one line per COO shows its latest outcome; a COO silent for over an hour shows red.
- The session lists are gone from the panel; the app's own sidebar already lists sessions.
