# Highlights

The "## Highlights" section of the next GitHub Release: 3-6 plain-language bullets of what users can now do.
Update it in the same change as the feature. CI fails when there are fewer than 3 or more than 6 bullets.

- Updates stick: a session that was already open before an update can no longer switch you back to the older version.
- New roles from an update (like the Communication VP) are set up on the next session start, with nothing to run.
- The Communication VP holds a message when your drafting tool declines or fails, and says why.
